## 1. フォルダの構成とモジュール同士のつながり

```
dev-rules/
├── README.md           入口。正本の対応表、版の運用、変更履歴
├── VERSION             版（v9）。各プロダクトの作業前の確認が読む

├── dynamic-test.md     動的テストの手順（A・B・C）
```

- 読む経路：各プロダクトの CLAUDE.md（claude-md-block.md の写し）→ 作業前の確認で VERSION を見る → 「読む先の表」で rules/*.md を選ぶ。common-rules.md は全作業で読む。

- 正本：枝、別チャット、止まるところ、安全は common-rules.md。claude-md-block.md の「基本の決まり」はその要点の写し。
- 写しが複数ある：claude-md-block.md、各プロダクトの CLAUDE.md、product-template の CLAUDE.md。版の値は VERSION、README.md、claude-md-block.md（「v9」）に現れる。
